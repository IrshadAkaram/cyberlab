JavaScript Prototype Pollution Kya Hai?What is JavaScript Prototype Pollution? JavaScript ek prototype-based language hai. Isme har object ke paas ek hidden link hota hai jise __proto__ (Prototype) kehte hain, jo aakhir mein global Object.prototype se judta hai. Agar koi property kisi object par nahi milti, toh JS upar prototype chain mein dhoondhta hai. Prototype Pollution ek aisi vulnerability hai jahan attacker recursive merge, deep clone ya JSON parsing flaws ka faayda utha kar is global Object.prototype mein nayi properties inject kar deta hai. JavaScript is inherently prototype-based. Every JavaScript object possesses a hidden reference called __proto__ pointing to its prototype, which terminates at the global Object.prototype. When a property is queried on an object, JavaScript traverses up the prototype chain. Prototype Pollution occurs when an attacker exploits unvalidated recursive merge, deep clone, or path-assignment functions to inject properties directly into Object.prototype.

Sabse Khatarnak Baat: Kyunki JavaScript runtime mein chalne wale LAGBHAG HAR OBJECT ka baap Object.prototype hota hai, isliye agar attacker ne ek baar prototype ko pollute kar diya, toh poore application ke har single object mein wo property automatically jud jaati hai! Isse attackers Privilege Escalation (e.g. isAdmin: true), Client-side DOM XSS, aur yahan tak ki Node.js server par Remote Code Execution (RCE) tak execute kar lete hain! The Devastating Impact: Because nearly every object in the runtime inherits from Object.prototype, polluting the root propagates the injected properties across EVERY existing and future object in memory! Attackers leverage this to achieve immediate Privilege Escalation, Client-Side DOM XSS, and full Remote Code Execution (RCE) on Node.js backends!

1. Kyun Banaye Gaye? (The Memory Optimization Problem)1. Why Were Prototypes Engineered?

JavaScript jab 1995 mein banayi gayi thi, tab yeh bina classical classes (C++/Java style) ke launch hui thi. Socho agar application mein 50,000 objects bante hain, aur har object ke paas apne khud ke functions (jaise toString(), valueOf(), hasOwnProperty()) alag-alag copy hote, toh browser ki RAM turant crash ho jaati! When JavaScript was created in 1995, it lacked classical class inheritance. If every instantiated object stored duplicate copies of standard utility methods (toString(), valueOf(), hasOwnProperty()) in its own memory heap, browser RAM would be exhausted instantly.

The Engineering Solution: JavaScript ne Prototypal Inheritance invent kiya. Ek single shared master object Object.prototype memory mein banaya gaya. Baaki saare objects sirf ek chhota sa pointer (__proto__) rakhte hain jo is master template ki taraf point karta hai. Isse hazaron objects bina RAM waste kiye saare built-in methods share kar lete hain. The Engineering Solution: JavaScript introduced Prototypal Inheritance. A single shared root object, Object.prototype, resides once in memory. Every other object merely maintains a lightweight reference pointer (__proto__) linking back to this master template, enabling thousands of objects to share built-in methods with zero memory duplication.

2. Kaise Kaam Karta Hai? (Under The Hood Traversal)2. How It Works Under The Hood

Jab code kisi object ki property ko call karta hai (e.g. user.isAdmin): When code queries an object property (e.g. user.isAdmin): 

// Step 1: Does user own 'isAdmin'? -> user.hasOwnProperty('isAdmin') -> false
// Step 2: Traverse up the prototype chain -> user.__proto__.isAdmin
// Step 3: Check Object.prototype.isAdmin -> If undefined, check Object.prototype.__proto__
// Step 4: Reaches null (End of chain) -> returns undefined!

1. Defense 1: Sensitive Keys Blacklisting & Whitelisting1. Defense 1: Sensitive Keys Blacklisting & Whitelisting

// ✅ SECURE: Reject dangerous keys during recursive merge or cloning
function safeMerge(target, source) {
    for (let key in source) {
        // Drop dangerous prototype pollution keys immediately!
        if (key === '__proto__' || key === 'constructor' || key === 'prototype') {
            continue; 
        }
        if (typeof source[key] === 'object' && source[key] !== null) {
            if (!target[key]) target[key] = {};
            safeMerge(target[key], source[key]);
        } else {
            target[key] = source[key];
        }
    }
    return target;
}

2. Defense 2: Objects Without Prototypes (Object.create(null))2. Defense 2: Objects Without Prototypes (Object.create(null))
