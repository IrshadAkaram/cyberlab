🔍 How This Attack Works

  • Attacker gains code execution

    Via XSS vulnerability, malicious browser extension, or a compromised CDN script — attacker can run arbitrary JavaScript on the victim's page.

  • Fake overlay is injected

    A pixel-perfect copy of the site's own design is placed over the real page. The URL bar still shows the real domain, so the user sees no red flags.

  • Urgency triggers action

    "Session expired" is a classic social engineering trigger. Panic causes users to type their password without scrutiny.

  • Credentials exfiltrated silently

    The form posts to the attacker's server. The overlay then disappears and the real page resumes — the victim may never notice.

🛡 How to Protect Yourself
🔑

Use Passkeys / MFA

Hardware keys and TOTP codes can't be stolen this way — stolen passwords become useless without the second factor.

🧩

Audit Extensions

Browser extensions have full page access. Only install from trusted publishers and regularly review what's installed.

🔍

Question Popups

Legitimate apps rarely ask for your password mid-session. When in doubt, close the modal and open a fresh tab.

🛠

CSP Headers (Devs)

Content-Security-Policy blocks inline scripts and restricts where forms can submit, limiting overlay injection attacks.
