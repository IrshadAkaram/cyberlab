🛡️ Architecture Remediation: Unkeyed Header Sanitization

Client-supplied unkeyed headers (jaise X-Forwarded-Host) ko CDN ya reverse proxy par strip karein aur backend application me kabhi untrusted host headers se absolute script URLs construct na karein.

❌ VULNERABLE: Dynamic Script Inclusion via Host

// Insecure Backend Code
app.get('/en/home', (req, res) => {
  const host = req.headers['x-forwarded-host'] || req.headers.host;
  res.setHeader('Cache-Control', 'public, max-age=1800');
  // Poisoned response stored under /en/home key!
  res.send(`<script src="//${host}/bundle.js"></script>`);
});

✅ SECURE: Static Asset CDN Domain & Proxy Sanitization

# Secure Nginx Reverse Proxy Config
# Strip client-controlled X-Forwarded-Host
proxy_set_header X-Forwarded-Host $host;

// Secure Backend Code
const FIXED_CDN = "static.company.com";
app.get('/en/home', (req, res) => {
  res.setHeader('Cache-Control', 'public, max-age=1800');
  res.send(`<script src="//${FIXED_CDN}/bundle.js"></script>`);
});
