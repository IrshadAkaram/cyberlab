🛡️ Architecture Remediation: Direct Entity vs DTO Projection

Frontend UI fields chupane se backend API secure nahi hoti. Hamesha Data Transfer Objects (DTO) ya explicit database projection use karein.

❌ VULNERABLE: Direct Model Return (Mass Exposure)

// Insecure: Returns full MongoDB/PostgreSQL entity
app.get('/api/user/profile', async (req, res) => {
  const user = await UserModel.findById(req.user.id);
  // Entire DB record sent to client:
  // includes password_hash, ssn, stripe_customer_id!
  res.json(user);
});

✅ SECURE: Explicit Field Whitelist & DTO Projection

// Secure: Strict projection at DB level
app.get('/api/user/profile', async (req, res) => {
  const user = await UserModel.findById(req.user.id)
    .select('username email avatar createdAt -_id'); // Only safe fields!

  // Or use dedicated Data Transfer Object (DTO)
  res.json({
    username: user.username,
    email: user.email,
    avatar: user.avatar
  });
});
