🛡️ Architecture Remediation: Mitigating Slowloris Attacks

Slowloris thread-per-connection architectures (jaise Apache Prefork) ko target karta hai. Solution hai front-end par asynchronous event-driven reverse proxy (Nginx) lagana aur strict header timeouts enforce karna.

❌ VULNERABLE: Unbounded Socket Timeout

# Insecure: Apache Default Config
Timeout 300
KeepAliveTimeout 15
MaxRequestWorkers 100

# Attacker keeps 100 sockets open indefinitely!

✅ SECURE: Reverse Proxy Buffering & IP Concurrency Limits

# Secure Nginx Reverse Proxy Configuration
client_header_timeout 5s;  # Drops slow headers after 5 seconds
client_body_timeout 5s;
send_timeout 5s;

# Strict connection limit per IP address
limit_conn_zone $binary_remote_addr zone=addr:10m;
limit_conn addr 15; # Max 15 concurrent sockets per client IP!
