🛡️ Architecture Remediation: Never Use ECB Mode For Data

Electronic Codebook (ECB) mode identical plaintext blocks ko identical ciphertext deta hai — jisse image pixel patterns aur repeated database records leak ho jaate hain. Always use GCM mode with unique Initial Vector (IV).

❌ VULNERABLE: AES-ECB Mode (Leaks Patterns)

// Insecure: Electronic Codebook mode without IV
const crypto = require('crypto');
function encryptData(key, plaintext) {
  // FLAKY: Identical plaintext blocks produce identical ciphertext!
  const cipher = crypto.createCipheriv('aes-128-ecb', key, null);
  return cipher.update(plaintext, 'utf8', 'hex') + cipher.final('hex');
}

✅ SECURE: AES-256-GCM Mode with Cryptographic IV

// Secure: Authenticated Encryption with Random IV
const crypto = require('crypto');
function encryptData(key, plaintext) {
  const iv = crypto.randomBytes(12); // Fresh 96-bit IV every time!
  const cipher = crypto.createCipheriv('aes-256-gcm', key, iv);
  const encrypted = cipher.update(plaintext, 'utf8', 'hex') + cipher.final('hex');
  const authTag = cipher.getAuthTag().toString('hex');
  return { iv: iv.toString('hex'), ciphertext: encrypted, tag: authTag };
}
