🔍 Technical Mechanics: Why CVE-2021-41773 Occurred

In Apache 2.4.49, developers introduced a newly optimized path normalization routine: ap_normalize_path() in server/util.c. To prevent directory traversal, this function scanned incoming paths for ../ dot-segments. However, the logic checked for literal dots ('.') without first decoding URL-encoded characters!

When an attacker supplied .%2e/ or %2e%2e/ (where %2e represents ASCII .), the normalization loop did not treat .%2e as two consecutive dots because the second character was %, not .. Later in the Apache request cycle, the server URL-decoded the path — converting .%2e/ into ../ and escaping the DocumentRoot! If mod_cgi was enabled, the traversal could reach /bin/sh with a POST request, resulting in Remote Code Execution.
