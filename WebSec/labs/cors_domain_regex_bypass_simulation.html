🛡️ Architecture Remediation: Never Use Unanchored Regex or Substrings

Origin validation ke liye indexOf(), endsWith() ya unanchored regex (jaise /corporate\.com/) use na karein. Attacker easily corporate.com.attacker.com ya notcorporate.com register karke bypass kar lega. Exact hostname match karein.

❌ VULNERABLE: Substring or Unanchored Regex

// Insecure Node.js / Express
app.use((req, res, next) => {
  const origin = req.headers.origin || '';
  // FLAW: Matches 'corporate-fintech.com.evil.com' and 'evil-corporate-fintech.com'
  if (origin.includes('corporate-fintech.com')) {
    res.header("Access-Control-Allow-Origin", origin);
    res.header("Access-Control-Allow-Credentials", "true");
  }
  next();
});

✅ SECURE: Exact Whitelist Match with URL Parsing

// Secure Node.js / Express
const TRUSTED_ORIGINS = new Set([
  "https://corporate-fintech.com",
  "https://app.corporate-fintech.com"
]);

app.use((req, res, next) => {
  const origin = req.headers.origin;
  // Strict exact comparison against authorized domains set
  if (origin && TRUSTED_ORIGINS.has(origin)) {
    res.header("Access-Control-Allow-Origin", origin);
    res.header("Access-Control-Allow-Credentials", "true");
    res.header("Vary", "Origin");
  }
  next();
});
