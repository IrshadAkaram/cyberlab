🛡️ How To Defend: Passing Null-Prototype Options to child_process

Node.js mein jab bhi child_process.spawn(cmd, args, options) call karein, toh options ko prototype-less banayein (Object.create(null)) ya explicit shell: false define karein taaki polluted properties use na ho sakein.

❌ VULNERABLE CODE (Inherits Global Prototype)

// Insecure: options argument is empty object
const { spawn } = require('child_process');

function runBackup() {
  // If Object.prototype.shell is polluted with "/bin/sh",
  // spawn executes command inside bash shell!
  const child = spawn('ls', ['-la'], {});
}

✅ SECURE REMEDIATION (Explicit & Prototype-less)

// Secure: Explicit options & null prototype
const { spawn } = require('child_process');

function runBackup() {
  // FIX: Force shell: false and clean null prototype
  const safeOptions = Object.assign(Object.create(null), {
    shell: false,
    env: { PATH: process.env.PATH }
  });
  const child = spawn('ls', ['-la'], safeOptions);
}
