🛡️ Architecture Remediation: Origin Allowlisting

Client request se aane wale Origin header ko kabhi bhi blind reflect na karein jab Access-Control-Allow-Credentials: true enabled ho. Server par ek immutable, explicit set of trusted domains banayein aur exact string match karein.

❌ VULNERABLE: Dynamic Origin Reflection

// Insecure Node.js / Express Implementation
app.use((req, res, next) => {
  // CRITICAL: Blindly mirrors any client-supplied Origin
  res.header("Access-Control-Allow-Origin", req.headers.origin);
  res.header("Access-Control-Allow-Credentials", "true");
  next();
});

✅ SECURE: Explicit Set Allowlist & Header Omission

// Secure Node.js / Express Implementation
const TRUSTED_ORIGINS = new Set([
  "https://app.company.com",
  "https://portal.company.com"
]);

app.use((req, res, next) => {
  const origin = req.headers.origin;
  if (TRUSTED_ORIGINS.has(origin)) {
    res.header("Access-Control-Allow-Origin", origin);
    res.header("Access-Control-Allow-Credentials", "true");
    res.header("Vary", "Origin");
  }
  // Untrusted origins receive NO CORS headers!
  next();
});
