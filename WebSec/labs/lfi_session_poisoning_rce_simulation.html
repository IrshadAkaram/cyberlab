🛡️ Architecture Remediation: Eliminate Local Session Files on Disk

Enterprise production architectures me PHP sessions ko disk par plaintext files me store na karein. Remote Redis/Memcached cluster use karein aur open_basedir restrict karein.

❌ VULNERABLE: Default Filesystem Sessions

; php.ini default (Insecure)
session.save_handler = files
session.save_path = "/var/lib/php/sessions"

# Any LFI can execute session files directly!

✅ SECURE: In-Memory Redis Session Handler

; php.ini hardened (Secure)
session.save_handler = redis
session.save_path = "tcp://10.0.0.5:6379?auth=secret"

# Enforce open_basedir confinement
open_basedir = "/var/www/html"
