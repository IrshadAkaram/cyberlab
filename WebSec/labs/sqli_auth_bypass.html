Why Did This Attack Work?

In string concatenation, the database treats single quotes (') as structural delimiters that define where a text literal begins and ends. When an attacker supplies a quote inside their input, the database engine thinks the developer's string literal has ended early. Subsequent characters (like -- or #) are parsed as SQL comment commands, telling the database to completely discard the rest of the query including the AND password = '...' check!

❌ Vulnerable: Dynamic Concatenation

# Attacker input modifies query syntax!
query = "SELECT * FROM users " \
        "WHERE username='" + user + "' " \
        "AND password='" + pass + "'"
cursor.execute(query)

✅ Remediated: Parameterized Query

# Query structure compiled first!
# Input is treated strictly as data.
query = "SELECT * FROM users " \
        "WHERE username = %s " \
        "AND password = %s"
cursor.execute(query, (user, pass))
