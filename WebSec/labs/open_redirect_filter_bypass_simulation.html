🛡️ Architecture Remediation: Reliable URL Validation

Regex aur string matching (jaise startsWith('/')) fail ho jaate hain kyunki browser //evil.com aur /\evil.com ko external schemes maanta hai. Always parse with the standard URL constructor.

❌ VULNERABLE: Naive String Matching / Regex

// Insecure: Naive check easily bypassed by //evil.com
app.get('/redirect', (req, res) => {
  const url = req.query.url;
  // FLAW: '//evil.com' starts with '/' but browser goes to evil.com!
  if (url.startsWith('/') || url.includes('target.com')) {
    return res.redirect(url);
  }
  res.redirect('/home');
});

✅ SECURE: Standard URL API + Strict Origin Whitelist

// Secure: Parse with standard URL constructor
app.get('/redirect', (req, res) => {
  try {
    const parsed = new URL(req.query.url, 'https://target.com');
    // Enforce EXACT origin matching
    if (parsed.origin === 'https://target.com') {
      return res.redirect(parsed.pathname + parsed.search);
    }
  } catch(e) {}
  // Default fallback
  res.redirect('/dashboard');
});
