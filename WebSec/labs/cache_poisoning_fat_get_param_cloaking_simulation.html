🛡️ Architecture Remediation: Block Fat GET Request Bodies

RFC 7231 specifies that GET requests should not carry payload bodies with defined semantics. Caching proxies and origin servers must ignore or explicitly reject bodies in GET requests.

❌ VULNERABLE: Framework Merges Body on GET

// Insecure: Merging req.query and req.body indiscriminately
app.get('/api/products', (req, res) => {
  const cb = req.body.callback || req.query.callback;
  res.setHeader('Cache-Control', 'public, max-age=1800');
  res.json({ id: req.query.id, callback: cb });
});

✅ SECURE: Strictly Reject Body on GET Methods

// Secure Middleware: Drop or reject body on GET requests
app.use((req, res, next) => {
  if (['GET', 'HEAD'].includes(req.method) && parseInt(req.headers['content-length']) > 0) {
    return res.status(400).send("HTTP GET with body not permitted!");
  }
  next();
});
