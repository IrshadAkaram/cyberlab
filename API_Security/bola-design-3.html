Exploiting Broken Object Level Authorization (BOLA)

Target Environment: api.corp-internal.net
Mission Goal: Aap User 1001 (Alice) ke credentials ke saath authenticated hain. BOLA vulnerability ka use karke User 1002 (John Doe) ke account me ghusein aur confidential data leak karein. Target Environment: api.corp-internal.net
Mission Goal: You are authenticated as standard user Alice (ID: 1001). Exploit the object-level authorization flaw to exfiltrate John Doe's (ID: 1002) confidential data.

1

Phase 1: Reconnaissance & Theory

BOLA tab hota hai jab server client ki aayi ID par bharosa kar leta hai bina ye dekhe ki token kiska hai. BOLA occurs when an API accepts client-provided IDs without asserting token tenant ownership.

🎯

AuthN vs AuthZ

AuthN verifies credentials (Login). AuthZ validates access rights to records (Object Ownership).
