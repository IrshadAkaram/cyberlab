What is BOLA? (BOLA Kya Hai?) What is BOLA?

Broken Object Level Authorization (BOLA), jise Web Pentesting me IDOR kehte hain, API Security ki sabse badi kamzori hai. Yeh tab hoti hai jab server token check kar leta hai par yeh check nahi karta ki maanga gaya record usi user ka hai ya kisi aur ka. Broken Object Level Authorization (BOLA), formerly known as IDOR, is the #1 vulnerability in API security. It occurs when an API verifies user identity but fails to verify whether that user has authorization to access the specific object requested.

ℹ

Aasan Bhasha Me In Simple Terms

Agar aap request me sirf ID badal kar (1001 ➔ 1002) kisi doosre user ka data dekh sakte ho, toh wahan BOLA hai! If you can change an ID parameter in an API request and see someone else's data, the API is vulnerable to BOLA.

Object Identifier ID Parameter

Database record ka unique identifier jaise user_id, order_id, ya UUID. The primary key identifying a record, such as user_id or UUID.

AuthN vs AuthZ Core Concept

AuthN: Identity verify karna (Login).
AuthZ: Resource access karne ka haq hona (Ownership). AuthN: Verifying identity.
AuthZ: Verifying permissions to touch a specific resource.

4 Real-World Attack Scenarios

💳 1. Sequential Invoice & PII Leakage
Critical

Attacker changes GET /invoices/9410 to loop through 9400–9500 to extract customer PII and credit receipts.

🏢 2. Multi-Tenant Tenant Hop
Critical

Changing tenant_id=418 to 419 leaks an entire competitor company's private workspace.

🔥 3. State-Changing Account Takeover
Critical

Using PUT /api/users/1002 with {"email": "hacked@evil.com"} overwrites another user's email.

🧩 4. Blind BOLA via Leaked UUIDs
High

UUIDs leaked in public profiles or forum comments allow attackers to query unprotected endpoints directly.

Confusing Questions & Answers

❓ Kya UUID use karne se BOLA solve ho jata hai?
Nahi! UUID guess karna mushkil banata hai, par access control nahi lagata. Agar UUID leak ho jaye toh BOLA fir se exploit ho jayega.
❓ BOLA aur BFLA me kya fark hai?
BOLA: Same-level users ke beech ka object leak (Horizontal).
BFLA: Normal user ka admin function call kar lena (Vertical).
